# 可复用文档模板

复制模板到目标目录并替换占位内容，不在模板本身填写任务结果。

| 模板 | 用途 |
| --- | --- |
| [Feature-Plan.md](Feature-Plan.md) | 多系统功能、架构/存储/接口变更的实施方案 |
| [Interface.md](Interface.md) | 新接口或现有接口语义/签名变更的契约 |
| [Change-Record.md](Change-Record.md) | 每次实质修改的事实与验证结果 |
| [ADR.md](ADR.md) | 需要长期追溯的架构取舍 |

日常使用与状态规则见 [维护工作流](../Maintenance.md)。
