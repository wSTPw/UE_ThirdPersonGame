## 已落地的执行路径

`AMHWICharacter::StartResolvedMove`在清理旧动作前，从实际选中的Montage段取得来源bank、片段和源帧；通过原FSM身份展开表选择连接。多个前置身份只有得到相同选择结果才允许使用节点适配；没有把ActionNo当MotionNo。连接阶段使用独立瞬态Montage，停止主招命中、防御、取消、转向和自动派生的时钟。连接结束后在同一执行代次提交主段，费用与动作切换事件不重复触发。

角色已调用`FLinkExecution`。26条原生连接片段由角色CDO硬引用，避免仅通过字符串查找而在打包时丢失。正式DataAsset当前仍有32招；其余原生前置玩法没有因这次连接接入而凭空实现。[逐条台账](../Plans/MHWI-Connector-Progress.md)区分当前可消费的前置动作、缺失的前置玩法和原图不可达节点。
