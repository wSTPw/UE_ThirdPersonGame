# 太刀取证结论总账

本页汇总 MHWI 太刀（`wp03` / 猎人 `w03_00`）**已确证的结论**和**仍未闭合的问题**。原始报告在 [Archive/MHWI/Reference/](../Archive/MHWI/Reference/)，本页不重复推导过程。

证据级别沿用项目五级：官方机制 / 原始数据 / 原生消费者 / 运行验证 / 项目推断。没有级别的陈述视为未取证。

`analysis-text.bin` 是解包后 `.text` 镜像，VA 基址 `0x140001000`；镜像偏移 = VA − 该基址。**不能**把这些 VA 当原 EXE 磁盘偏移。

**覆盖警告**：当前安装存在 5 项 `nativePC` 覆盖。其中 `wp03.col` 安装版 `37ccaace...` 与归档原件不同——52 条攻击记录的 `Flinch_Value` 被改，其余几何/UID 映射一致。复现任何数值结论前先记录覆盖状态。

## 一、数值参数（`wp03_param.w03p`，1584 B）

425 个标量/文本字段覆盖 1572 B，其中 100 项有上游名称，尾部 12 个零字节保留为未解释区。布局依据 Synthlight/MHW-Editor 固定 commit `b6ff379b13079a4abb99490590fb05dfe6851bbc` 的 `Wp03Param.cs`。

| 字段 | 偏移 | 源值 | 项目值（0–100 槽） |
| --- | --- | --- | --- |
| 气刃 I/II/III/回旋消耗 | `0x4a1..0x4ad` | 0.15 / 0.15 / 0.20 / 0.25 | 15 / 15 / 20 / 25 |
| 正常见切所需槽 | `0x4c5` | 0.1 | 10（阈值按扣费前槽判断） |
| 白/黄/红持续 | `0x4f1..0x4f9` | 195 / 135 / 60 秒 | 同 |
| 回旋升级后停止衰减 | `0x51d` | 10 秒 | 见未解项 U3 |
| 见切伤害倍率 / 霸体 | `0x525` / `0x534` | 1.3 / 1 秒 | 同 |
| 居合保持 / 霸体 | `0x540` / `0x544` | 3.5 秒 / 2 秒 | 同 |
| 居合回槽 | `0x4e1..0x4ed` | 普通 15 s / 反击 30 s，period 15 | 100/15 每秒 |
| 登龙回槽 | `0x4d1..0x4dd` | 非红 10 s / 红 15 s，period 15 | 同 |
| 居合速度 | `0x53c` | 0.4 | 已提取，未套 PlayRate |
| 登龙命中延迟 / 上限 | `0x5f8..0x604` | 首击 0.4 s、后续 0.05 s、上限 7 | 同 |

百分比转换保留 float32 的 7 位有效十进制精度，避免 `0.150000006 × 100` 变成 15.000001。

**气刃踏步 cost 0x4b1 = 20 的语义**（易误读）：不是弱斩启动门槛，而是**强化消费**。原 COL 记录显示不足槽走 18 的弱斩且不扣槽，够 20 才用 28 并扣 20；命中回槽 10。

复现：

```powershell

python Scripts/MHWI/build_native_action_database.py
```

产物 `Saved/MHWIImport/NativeParameterResearch-20261024/native-action-database.json`：425 字段、164 动作全部 TIML、90 个 FSM 节点 / 307 条有序边 / 307 棵条件树、299 条输入轨 / 961 key、4 条完整 IK 链（左臂 6/7/8、右臂 10/11/12、左腿 14/15/16、右腿 18/19/20，XFS19 完整消费 5982 B/件）。

## 二、装备挂接（原生消费者已闭合）

原生路径分两条：`uWeaponMain`（刀，调用者 `0x142119010` 传 `dl=1`）、`uWeaponSub`（刀鞘，`0x14211b0a0` 传 `dl=0`）。挂点由 `0x14210d360` 扫描 usage=2、功能号 30/47 的**缩放轨 Y 通道**得出——Y 值是选择标记，不是几何拉伸，不向装备传播。

| 选择结果 | 功能骨 | 骨架路径 | 变换来源 |
| --- | --- | --- | --- |
| 0 | 2 | `bone_002` | 背部配置 × 背部骨变换 |
| 1 | 47 | `bone_012 → bone_047` | 辅助骨 47 |
| 2 | 30 | `bone_008 → bone_030` | 辅助骨 30 |

匹配容差 0.1，按原始记录顺序取首个匹配；3.9–4.1 为共享标记。`30/47` 是随动画变化的专用辅助骨，**不是**固定腕骨，项目旧的左右手标签不能代替骨号关系。

背部配置（武器类型 3，主副两条相同）：功能骨 2，源欧拉角 `(89,-4,41)`，源平移 `(-47,51,-24)`，比例 `0.8`，旋转组合 `qz*qy*qx`。标准辅助骨挂接比例 1；比例过渡 0.15 秒圆形 ease-out。

导入坐标（源 LMT 与 UE 动画对照得出，84 组最大平移误差 8.28e-5 cm、旋转误差 7.44e-5°）：

```text
局部坐标反射 D = diag(1,-1,1)；UE 根旋转 = Rx(-90°)
C = Rx(-90°) * D，即 (x,y,z) → (x,z,y)
原始局部平移 (x,y,z)     → UE 骨局部 (x,-y,z)
原始四元数 (x,y,z,w)     → UE 骨局部 (-x,y,-z,w)
装备局部基修正四元数      = (0.70710678,0,0,0.70710678)
```

| `w03_00_001`/`102`/`105` | 全片段 | 2 | 0 |
| `w03_00_002` | 0..15 / 16..59 / 60..70 | 0 / 1 / 2 | 0 |

即：普通攻击刀在辅助骨 30、鞘背挂；特殊纳刀刀在 47、鞘在 30；拔刀/退出/居合在片段内部切换。**不能**写死骨号，也不能从 `bSheathed` 或 `mWeaponMotionNo` 单独推导切换帧。

## 三、武器碰撞（结论：原作数据不可直接用）

| 问题 | 结论 | 级别 |
| --- | --- | --- |
| 原作有武器攻击碰撞数据？ | 是。`.col` 含 59 条攻击记录、55 个表头引用（52 条记录）、13 组 CLND/CLGM 几何 | 原始数据 |
| 由动作时间控制？ | 强静态支持。39 条 `CollisionTimelineObject` 轨的 `NodeID[0]` **39/39** 匹配 `.col` 的 `timeline_uid` | 原始数据 |
| 是刀刃网格/特定几何体？ | **不能判定**。社区模板把多数几何字段留作 `Unk_*` | — |
| CLND 类型 1 是什么？ | 节点工厂类 `cCollNodePl`（0x58 B），**不是几何形状类型**。链：`0x14191a5c0` → 工厂表 `0x143f94a18` → 静态初始化 `0x140009890` 注册名称/vtable | 原生消费者 |
| 挂在刀身骨骼/Socket？ | **不能判定**。CLGM 13 组未映射到 `cGeometryJoint`，字段语义/骨骼索引/空间变换全缺 | — |
| 伤害按部位查肉质？ | **不能判定**。部位选择与肉质行选择未闭合 | — |

**已作出的决策**：原作 `.col` 暂不作为项目刀刃碰撞依据，转项目自己的武器/骨骼扫掠方案。要复用原作形状，仍需运行时对象/骨骼观测。

单招示例 `w03_00_101`（项目暂称 StepSlash）：`NodeID=44`，`mFlag` 第 55 帧 0→1、第 66 帧回 0，关联攻击记录 8 / 几何组 0 / `Motion_Value=24`。

复现：

```powershell
python Scripts/MHWI/audit_weapon_hit_volume_evidence.py
python Scripts/MHWI/trace_weapon_collision_loader.py
```

## 四、动画与连接（LMT / MBD / FSM）

- 源审计覆盖 164 动作的全部 19 类 TIML、90 个 FSM 节点、307 条条件/连接。旧五类过滤器遗漏 954 个事件组。
- `w03_00.mbd` 解析出 30 个连接节点、32 次片段引用。正式 32 招 Montage 仅覆盖其中 129 一处，其余 31 次未调度。
- **左右映射冲突（未解）**：FSM 名称/箭头/Action 与 MBD 明确一致为 左 128/node8/Action82、右 127/node9/Action83；但 `361→127@22`、`362→128@24`。来源冲突已记录，正式动画未改。
- 26 段原生采样片段导入 `/Game/MHWI/Animations/R06Staging`；角色已消费连接核心（源帧 Phase、原生结束 flags、MBD 默认行入帧）。
- 基础移动：`idle/walk/run/sheathed_*` 与两张 BlendSpace 六样本取自 `A_w03_00_001`（hold REF_POSE 锁根）、`A_w03_00_004`、`A_co00_00_001/203/090`。速度 180/420、倍率与混合均为**项目适配**。
