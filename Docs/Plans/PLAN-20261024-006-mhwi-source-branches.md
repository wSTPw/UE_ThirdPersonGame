## 技术方案

1. 固定指纹原COL/W03P/FSM直接重读并导出相关记录、原条件树和有序边；一手表仅佐证弱/强消费语义，18/28/20/10仍全取原文件，记录源偏移与转换。
2. 复用`bAllowWeakSpiritAttack`、`WeakDamageMultiplier`、`WeakSpiritGain`；正常窗口基值设为源条件替换28，弱倍率按18/28生成，cost20/weak gain10从源字段生成。保持当前统一命中适配器边界。
3. `FMHWIRoute`新增可选`RequireFullSpiritCost=false`。仅启用的路由在`ResolveInput`中读取目标定义的SpiritCost判资格，失败继续扫描后续同输入路由；不在运行时代码硬写20，不对所有旧路由增加新限制。
4. 为`SpiritComboRisingSlash`的现有R→III启用该条件，紧随其后插入R→I，保持其他先决条件、已存在窗口、目标和优先级。
5. 原生分支修复器提供复制结构预览、完整保护、幂等及正式DA备份/保存/读回；基础制作尾处理复用，B01入口再运行也不回退B02。窗口配置同步新增/删除的同输入路由规则，不添加猜测数值。
