# PLAN-20261019-001：像素风格主菜单

- 状态：implemented
- 日期：2026-10-19
- 用户需求：规划并美化 `UW_MainHUD`，允许调整位置和新增 UI，生成一套可落地的像素风格贴图。
- 关联模块 / 接口 / 问题：`UUW_MainHUD`、`/Game/MyStuff/MyUI/UW_MainHUD`
- 实施记录：[CHG-20261019-001](../Changes/CHG-20261019-001-main-menu-pixel-ui.md)。

## 现状与目标

运行画面已核实为纯灰背景、中央纵向排列的三个灰色按钮，未设置背景纹理、装饰层或动画。Widget Blueprint 父类为 `UUW_MainHUD`，必须保留 `Button_StartGame`、`Button_1`、`Button_2` 三个可绑定按钮。

目标是形成统一的像素奇幻主菜单：全屏场景背景、标题徽记、菜单框、三态按钮及辅助文字。布局适配 16:9，并让标题与主要操作在 1280×720 和 1920×1080 下保持清晰层级。

## 范围与验收标准

- 生成并保存主菜单背景、标题徽记、菜单面板和按钮状态贴图的 PNG 源文件。
- 将贴图导入 `/Game/MyStuff/MyUI/MainMenu/Textures`，采用适合 UMG 像素素材的设置。
- 重排 `/Game/MyStuff/MyUI/UW_MainHUD` 并新增装饰及文字组件。
- 保留三个必需 BindWidget 名称和当前点击行为，不在本次扩展设置、退出或存档功能。
- Widget Blueprint 可编译、保存；PIE 可显示主菜单并留存实际截图。

## 技术方案

视觉采用深靛蓝遗迹、青绿色魔法光和暖金色交互高光。背景负责空间氛围，透明徽记和面板负责视觉层级；按钮文字继续由 UMG 渲染，避免把中文固化在图片内。

根 Canvas 保持全屏。背景和暗角铺满；标题徽记位于上方；菜单面板置于画面视觉中心偏左或中央；三个按钮纵向等距排列；底部增加开发版本与操作提示。控件名称只对新增的非绑定组件自由命名。

## 实施步骤与依赖

1. 保存当前运行截图作为视觉基线。
2. 生成无文字的像素背景、透明徽记、面板及按钮状态素材，并复制到项目源素材目录。
3. 通过 UE-MCP 导入纹理，设置 UI 压缩、无 Mipmap 和最近邻过滤。
4. 修改 `UW_MainHUD` 的层级、锚点、尺寸、文本和按钮样式，编译并保存。
5. 进入 PIE 截图，核对绑定控件、布局和启动按钮可见性。
6. 更新 UI 资产契约、变更记录和索引。

## 风险与回退

主要风险是生成图边缘透明度、纹理拉伸和二进制 Widget 资产修改。通过九宫格边距或固定尺寸减少拉伸；按钮文字不烘焙进贴图。回退时恢复 `UW_MainHUD.uasset`，删除本次新增的纹理资产和对应源 PNG；C++ 行为不受影响。
