## 怎么写新方案

1. 复制 [功能方案模板](../Templates/Feature-Plan.md)，命名 `PLAN-YYYYMMDD-NNN-主题.md`
2. 在"活跃"表加一行
3. 方案落地后：更新现状页 → 写 `Changes/CHG-*` → 把本文件移入 `Archive/` 并删掉这一行

**方案不是现状。** 读者看到 `Plans/` 里的内容默认是"打算做"，不是"已经做了"。已实现的部分必须写进 `Systems/`。
