1. 新增项目自有的原生采样转换，不修改第三方插件或原始LMT/.blend；平行FBX至少覆盖拔刀、纳刀、129、173、特殊纳刀和居合气刃。验证坐标、根轨迹、骨矩阵、时长、子帧和FBX重读后，才进入正式引用。
2. 武器家族/骨架匹配有证据后导出武器动画；源mWeaponMotionNo作为独立轨道消费。整件装配、交接/可见性与内部手柄运动分别处理，不能将一种效果冒充另一种。
3. 用户要求改用较轻的方式：公开研究帧表、原作者教程及 UE 动作对照交叉校准；不要求用户准备原作进程采样。已有源结构保留作辅助，未知字段不能批量猜时序。[公开资料与实施边界](../Reference/MHWI-Native-Fidelity-Implementation.md) 分开列出可用数字和仍缺失的逐路由窗口。
