## 原因与结果

`dtt_eda` 此前停在 888/896 未发布数值。本轮确认剩余 8 字节为**全零**，按项目既有 B13 部位解析器相同的零尾判据（`expected_zero_tail`）处理，26 段全部读到并通过，状态值可发布：

- 毒 250/150/700、睡眠 150/100/550、麻痹 180/130/570、`Stun` 120/100/620、疲劳累积 225/75/900、乘骑 40/70/460、爆破 120/60/720、捕获 150/200/300。
- **口水硬（`Clagger`）Base 300 / 上限 300**；气绝（`Dizziness_LR_HR`）持续 20 s、每次 −4 s、最小 5 s。
- 陷阱：麻痹 8 s、落穴 10 s（均每次 −2 s、最小 2 s）、藤蔓 8 s。
- 捕获阈值 下位·上位 30% / 大师 25%；发怒累积（钩爪）30/30/35/30/30。

`em_pbc` 只做到结构可见，**字段语义未定，未输出任何阈值**：头 16 字节 = `01100918` / `9` / `PBC\0` / 记录数 5；`16+5×48=256` 与 `36+5×44=256` 同时成立，无法唯一确定记录边界。5 条记录前 20 字节相同（3 个疑似部件哈希 + 两个 1），尾部变值为 `5/1/4/3/2` 等，含义未知。原始字节已按 48 字节切分抄入数据页备查，明确标注不可当耐久使用。
